Rencana Implementasi: Dompet Sehat (Healthy Wallet)
Aplikasi web manajemen keuangan pribadi yang ramah pengguna, berpenampilan modern dan premium, 
berfokus pada kesehatan finansial pengguna dengan sistem login, pengaturan profil, pencatatan transaksi, 
visualisasi grafik, budgeting 50/30/20, dan skor kesehatan finansial.

Arsitektur & Rekomendasi Database Gratis
IMPORTANT

Mengapa Supabase (PostgreSQL Cloud Gratis)? Banyak server gratis (seperti Vercel atau Render free tier) 
akan menghapus file lokal (seperti file SQLite biasa) saat server restart atau tidak aktif. Oleh karena itu, kita menggunakan Supabase (PostgreSQL):

100% Gratis (Free Tier hingga 500 MB database & 50.000 pengguna aktif).
Dashboard Visual: Anda bisa melihat dan mengedit data tabel layaknya Excel / phpMyAdmin langsung dari browser.
Hosting Gratis Tanpa Batas: Sangat kompatibel dengan Vercel atau Netlify (cukup hubungkan GitHub, 
aplikasi langsung online dengan domain gratis .vercel.app dan HTTPS otomatis).
Local / Offline Fallback: Aplikasi juga akan dilengkapi mode penyimpanan lokal (Browser Storage / SQLite mock) 
sehingga Anda bisa langsung mencoba dan menjalankan aplikasinya di laptop Anda sekarang tanpa harus mendaftar Supabase terlebih dahulu.

Fitur Utama yang Akan Dibangun
Sistem Autentikasi Lengkap:

Register akun baru (Nama, Email, Password).
Login & Logout dengan enkripsi aman dan manajemen sesi pengguna.
Mode Cepat / Guest Demo untuk uji coba instan.
Pengaturan Profil Pengguna:

Ubah Nama, Avatar/Foto profil, dan Email.
Pengaturan Mata Uang (IDR Rp, USD $, EUR €, dll.).
Pengaturan Saldo Awal & Ubah Kata Sandi (Password).
Indikator Kesehatan Finansial (Health Score):

Skor Dinamis (0 - 100) berdasarkan rasio pengeluaran terhadap pendapatan.
Status visual: 🟢 Sehat Prima, 🟡 Waspada, 🔴 Kritis.
Analisis & tips otomatis untuk memperbaiki pengeluaran.
Pencatatan Transaksi & Kategori:

Input cepat Pemasukan & Pengeluaran (Nominal, Kategori, Tanggal, Catatan).
Filter berdasarkan bulan, tipe, atau pencarian nama transaksi.
Kategori default cerdas (Makanan, Transport, Belanja, Tagihan, Gaji, Investasi, dll.).
Budgeting 50/30/20 & Visualisasi Interaktif:

Alokasi otomatis: 50% Kebutuhan, 30% Keinginan, 20% Tabungan/Investasi.
Progress bar status penggunaan budget.
Grafik arus kas bulanan & diagram breakdown pengeluaran per kategori.
